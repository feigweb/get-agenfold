# Agenfold

Official macOS beta releases for Agenfold. This repository contains release notes and signed installers; it does not publish the application's source code.

- Website: <https://agenfold.vercel.app>
- Latest release: <https://github.com/get-agenfold/get-agenfold/releases/latest>
- Supported platform: Apple Silicon (arm64), macOS 26 or later

Each DMG is Developer ID signed and Apple notarized. Before installing, compare the downloaded file's SHA-256 with the value in its release notes. Open the DMG and drag Agenfold to Applications.

Agenfold keeps project goals, decisions, and progress in a project-local record and installs a skill that asks supported coding agents to read and update it. This is a document-based handoff: it does not automatically share chat history, guarantee that an agent follows the skill, or summarize changes between sessions.
