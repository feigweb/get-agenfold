# Agenfold 0.1.0 Beta

First public beta release for Apple Silicon Macs running macOS 26 or later.

## Download

- `Agenfold-arm64.dmg` — 146,285,653 bytes
- SHA-256: `fa40bd77a104b57608cad4a579ee7675c14028e1132e77ffaf2a7c2af90aedea`
- Developer ID signed and Apple notarized

## Included

- A Mac workspace for supported coding-agent sessions, project files, and tools.
- Project-local goals, decisions, and progress documents, plus a skill that asks supported agents to read and update the shared record.
- Preview, backup, and restore flows for supported Skills/MCP configuration changes.

## Current handoff boundary

The project record is document-based. Agenfold does not automatically share chat history, guarantee that an agent reads or updates the record, or produce an automatic between-session change summary.

Website and alternate download: <https://agenfold.vercel.app>
